# GatoTec Labs

> Ecosistema integrado de ingeniería para soporte técnico, gestión operativa y plataformas de autoservicio para clientes.

---

## 🏛️ Proyectos del Ecosistema

| Proyecto | Tipo | Tecnologías Clave | Propósito |
| :--- | :--- | :--- | :--- |
| **[gato18](https://github.com/gatotec-labs/gato18)** | Desktop App Nativa | Tauri 2.0, Rust, React 18, Tailwind, NextUI | Estación operativa para técnicos con soporte offline-first y generación de diagnósticos/garantías en PDF. |
| **[gato18Clientes](https://github.com/gatotec-labs/gato18Clientes)** | Portal Web de Clientes | React 18, Vite 6, Supabase, NextUI | Portal de autoservicio para consulta de tickets, seguimiento de garantías y estado de equipos en tiempo real. |
| **[gato18-fullstack](https://github.com/gatotec-labs/gato18-fullstack)** | Plataforma Web Fullstack | Rust (Axum + SQLx), React (HeroUI), PostgreSQL, Docker | Plataforma web desacoplada de dependencias externas, lista para despliegue soberano en VPS con Docker Compose. |

---

## 🧭 Principios de Diseño e Ingeniería

1. **Rendimiento Nativo & Eficiencia**:
   Aprovechamiento de Rust tanto en el backend de alto rendimiento (Axum) como en el frontend de escritorio ligero (Tauri 2.0).
2. **Soberanía y Desacoplamiento**:
   Capacidad de operar tanto de forma desacoplada con PostgreSQL local como con arquitecturas BaaS reactivas (Supabase).
3. **Resiliencia Operativa**:
   Diseño tolerante a desconexión (*offline-first*) para garantizar la continuidad del soporte técnico en cualquier circunstancia.
